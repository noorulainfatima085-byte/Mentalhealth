Project Description (Short & Simple)
This project is a Mental Health Chatbot built using Python and Streamlit.
It allows users to chat in real-time and share their thoughts or feelings.
The chatbot uses AI (OpenAI API) to generate supportive and helpful responses.
Users must enter their own API key to start the chat securely.
The system is designed to provide emotional support, stress relief tips, and guidance.
It maintains a chat history during the session for better conversation flow.
The interface is simple, user-friendly, and interactive.
The chatbot focuses only on mental health and well-being topics.
It helps users feel heard and supported in a safe digital space.
This project demonstrates the use of AI in healthcare support systems.
